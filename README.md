## 🌟 **Overview**

The **Age Calculator App** is a sleek, fully responsive web application that instantly computes your exact age in years, months, and days.  
Built with **pure HTML, CSS, and JavaScript** — no frameworks, no bloat — it delivers a seamless user experience with real‑time validation, smooth animations, and a modern, accessible interface.

> ⚡ **Why you'll love it :**  
> - Lightning‑fast calculations with zero dependencies.  
> - Animated counters that bring results to life.  
> - Pixel‑perfect design inspired by premium UI challenges.  
> - Fully keyboard and screen‑reader accessible.  

---

## ✨ **Features**

| **Category**        | **Details**                                                                 |
|---------------------|-----------------------------------------------------------------------------|
| 🧮 **Precision**    | Calculates years, months, and days **exactly**, handling leap years and month‑end transitions. |
| 🎯 **Validation**   | Instant inline error messages for empty, out‑of‑range, or impossible dates. |
| 🌀 **Animations**   | Subtle count‑up animation with easing (cubic‑out) for a polished feel.     |
| 📱 **Responsive**   | Adapts beautifully from large desktops to mobile phones (down to 320px).   |
| ♿ **Accessibility** | ARIA labels, `aria-live` regions, semantic HTML5, and full keyboard navigation. |
| 🎨 **Customisation**| CSS variables make rebranding painless — change the purple to your style.  |
